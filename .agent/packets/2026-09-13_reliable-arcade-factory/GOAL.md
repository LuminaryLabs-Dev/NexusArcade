# NexusArcade — Reliable Arcade Factory

Build a usable local arcade harness that reliably generates, styles, validates and presents 1,000 distinct Three.js/NexusEngine games.

Start with [the full 33-goal plan](PLAN.md). [RULES.md](RULES.md) defines mandatory behavior; [goal-queue.json](goal-queue.json) indexes authoritative intent and revisable interpretation for each goal. Goal specifications are in goals/. Every Plan goal produces a bounded execution packet for its following Build goal.

The existing master-catalog.json and game-profile.example.json remain illustrative draft contracts, not live runtime configuration. Their planned options need source-backed capability auditing. The earlier profile-validation plan has been expanded into this arcade-delivery packet.

Current authorization: implement the plan. Foundation source, contracts and player UI are being built and tested; historical generated games remain immutable. G01 is in progress and no factory goal is complete. Long-term targets do not constitute measured capability. Three.js remains the selected runtime; "unique" does not introduce Unity-engine work.
