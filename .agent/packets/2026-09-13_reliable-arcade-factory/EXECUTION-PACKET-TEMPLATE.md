# Per-cycle execution packet

Produced by goals 01,04,07,10,13,16,19,22,25,28,31 before the following Build job.

- Goal IDs and versions; authoritative intent and reviewed interpretation.
- Audited baseline, source hashes, supported capabilities and explicit gaps.
- One bounded ordered work list: shared changes first, verification, then admitted game attempts.
- Exact scope, outputs, batch slot ownership and definition of done.
- Frozen acceptance parameters, independent negative cases and comparison baselines.
- Feature/dependency graph, lock invalidation and rollback strategy.
- Deadline admission rules, cancellation, checkpoint/resume and failed-idea handling.
- Evidence manifest, review handoff and unresolved blockers.

One queue job may checkpoint and resume; it does not mean 100 games complete in one model call or 25 minutes. New unapproved product scope stops at a blocker. Shared RULES.md applies without duplication.
